# Dataset verification

Reviewed 20 November 2026. Each enabled input is pinned by publisher revision or named release and SHA-256 in the registry. Every report records the digests it used. An excluded source has no approved artifact. The commercial-only switch includes a source only when its registry entry explicitly permits it.

| Dataset | Publisher evidence | Phase 0 use |
|---|---|---|
| RAID | The dataset card tags the release MIT. The source material spans books, reviews, articles and other corpora. [Dataset card](https://huggingface.co/datasets/liamdugan/raid) · [Collection and splits](https://github.com/liamdugan/raid) | Research training and evaluation. Use the labeled clean training file with a prompt-group split. The optional attack shard is a pinned subset of the public conversion. Official test labels are withheld. Underlying source rights have not been cleared for commercial training. |
| MAGE | The card and repository license say Apache 2.0. The project's README displays CC BY 4.0. The compilation draws on ten source datasets. [Dataset card](https://huggingface.co/datasets/yaful/MAGE) · [Project README](https://github.com/yafuly/MAGE) · [License](https://github.com/yafuly/MAGE/blob/main/LICENSE) | Held-out evaluation only pending reconciliation. The loader inverts the publisher's labels so generated text is consistently 1. |
| PADBen | The Task 1 card states MIT and records its source corpora, sentence-level format and label mapping. [Dataset card](https://huggingface.co/datasets/JonathanZha/PADBen-Task1) | Evaluation only. The labeled train file supplies the research examples. Individual short paraphrases fall below Quick's length gate. |
| Liang et al. | The project carries an MIT badge and distributes paired documents and detector outputs. Its TOEFL and US comparison texts originate outside the project. [Project and data layout](https://github.com/Weixin-Liang/ChatGPT-Detector-Bias) · [Paper](https://arxiv.org/abs/2304.02819) | Evaluation only. The runner labels the Hewlett cohort as a US native-writer proxy. It makes no individual language-background inference. |
| PERSUADE 2.0 and ELLIPSE | Both publisher READMEs identify the data as CC BY 4.0. This differs from the master plan's NC-SA designation. [PERSUADE](https://github.com/scrosseye/persuade_corpus_2.0) · [ELLIPSE](https://github.com/scrosseye/ELLIPSE-Corpus) | Kept under the plan's research-only and share-alike handling pending a project licensing decision. The two registry booleans express this project handling. |
| ASAP 2.0 | The publisher explicitly states CC BY 4.0 for the corpus. It includes essays from PERSUADE. [Release and attribution](https://github.com/scrosseye/ASAP_2.0) | Use the public training archive and preserve attribution. Group the same normalized essay across sources and remove exact duplicates. Commercial-only filtering currently leaves human labels only and cannot fit a binary detector. |
| DAIGT | The Kaggle competition publishes separate terms. A general downstream grant for a hosted detector was not verified. [Competition rules](https://www.kaggle.com/competitions/llm-detect-ai-generated-text/rules) | Excluded from fetching, training and evaluation. |

Reports contain aggregate measurements. Raw source texts stay in the dataset cache and are omitted from Git. The consent and content of submitted user checks play no role in these datasets.
